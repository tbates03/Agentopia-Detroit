# Culture and Community Calendar Packs

These packs provide calendar context to Agentopia World Context.

## Rules

- Maximum 50 holidays/observances per calendar pack.
- Preserve native-language names when possible.
- Community/cultural packs require provenance.
- A country is not automatically treated as one culture.
- TAi must not infer culture, religion or holiday observance from a citizen's name, race, nationality, location or language.
- Community-specific packs should only be assigned to citizens through explicit world configuration.
- Public/civic calendars may be applied world-wide when the world explicitly enables them.

Supported date rules:

- fixed month/day
- nth weekday of a month
- last weekday of a month
- explicit date lists for calendars that require community-maintained or non-Gregorian calculations

Machine translation alone is not cultural validation.
