# Agentopia Community Research

This directory contains the public, opt-in research layer for the **Agentopia World League** and **TAi — Transparent AI** right-sizing research.

Structure:

    research/
      schema/
        world_beacon.schema.json
        research_pack.schema.json
      submissions/
        *.json
      packs/
        *.json
      world_profile.example.json

World Beacons report durable simulation progress and aggregate model-performance metadata.

Research Packs contribute testable tasks, jobs, trades, languages, and regional/cultural workflow context.

## Language Rule

**Submit the task in the language in which the work is actually performed.**

An English summary is optional and secondary.

## Transparency Rule

Every contribution should preserve provenance. Do not present invented stereotypes or machine-generated cultural assumptions as community knowledge.

## Consent Rule

Research/evaluation consent and model-training consent are separate fields.

Submitting a task for public right-sizing research does not automatically grant permission to use it for model training or fine-tuning.
