# Security Policy

Agentopia Detroit is experimental research software.

The cyber, adversarial, faction and mission systems are intended for synthetic Agentopia environments.

Do not commit or submit:

- API keys
- passwords
- private keys
- cloud credentials
- access tokens
- personal private data
- real victim information

Local configuration such as config.json must remain outside Git.

Security-sensitive reports should avoid publishing credentials or operational secrets in public issues.
